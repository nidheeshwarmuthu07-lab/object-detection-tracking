# Real-Time Object Detection and Tracking

This project performs real-time object detection and tracking using YOLO11 and ByteTrack.

## Features

- Live webcam detection
- Object detection using YOLO
- Object tracking using ByteTrack
- Unique tracking IDs
- Bounding boxes
- Confidence scores
- Streamlit web interface

## Technologies Used

- Python
- YOLO11
- Ultralytics
- OpenCV
- ByteTrack
- Streamlit
- WebRTC
